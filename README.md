# SDR-Based DVB-T Transmission/Reception Chain

## Overview

This project presents the design and experimental evaluation of a complete DVB-T transmission and reception chain based on Software Defined Radio (SDR).

The implementation was developed using **GNU Radio** and experimentally validated using the **NI USRP 2920** platform.

## Technologies

* GNU Radio
* NI USRP 2920
* DVB-T
* OFDM
* 16-QAM
* 64-QAM
* SDR

## Main Contributions

* Implementation of a complete DVB-T TX/RX chain
* OFDM modulation and synchronization
* Channel coding and decoding
* Experimental evaluation on real SDR hardware
* Performance comparison between 16-QAM and 64-QAM
